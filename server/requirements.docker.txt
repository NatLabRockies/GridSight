# GridSight server — Docker install spec.
#
# This file is the canonical dependency list for the production image.
# Local dev still uses pyproject.toml + uv (with editable installs from
# sibling repos); the container build uses THIS file so deps are pinned
# to remote sources reachable from any build environment.
#
# Each non-comment line is a pip-style requirement. Anything pip
# understands works:
#   - PyPI:        `package>=1.2.3`
#   - Git tag:     `package @ git+https://host/org/repo.git@v1.2.3`
#   - Git branch:  `package @ git+https://host/org/repo.git@main`
#   - Git commit:  `package @ git+https://host/org/repo.git@<sha>`
#   - Subdirectory:`package @ git+https://host/org/repo.git@<ref>#subdirectory=path/to/pkg`
#   - Wheel URL:   `https://host/path/to/wheel.whl`
#
# Adding a new extension to the image = appending one line here and
# rebuilding. Extension-specific environment variables go in `.env`.

# ── First-party extensions (bundled in this repo) ─────────────────────────
# SEDS (EIA State Energy Data System) lives in-repo at extensions/seds, so it
# ships with the server — no separate repo/ref to bump. Pinned to main like
# the SDK so it matches the server code being containerised. (Migrated out of
# the DemandTldr package; it's a small first-party dataset extension.)
gridsight-seds @ git+https://github.com/NatLabRockies/GridSight.git@main#subdirectory=extensions/seds

# ── External extensions (own repos) ──────────────────────────────────────

# instead (see docker-build.sh + .env.example).
